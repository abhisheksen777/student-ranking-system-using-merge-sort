Algorithm Explanation

What is Merge Sort?

Merge Sort is a Divide and Conquer algorithm. It works by recursively dividing the problem into smaller subproblems, solving them, and then combining the results.

Three Stages:

1. DIVIDE

Split the student records into two halves. Continue splitting until each sublist has one element.

2. CONQUER

Recursively sort each half. A single element is already sorted by definition.

3. COMBINE

Merge the sorted halves back together by comparing marks. Larger marks come first (descending).

Pseudocode

MERGE_SORT(A, low, high)

IF low < high
    mid = (low + high) / 2
    MERGE_SORT(A, low, mid)
    MERGE_SORT(A, mid + 1, high)
    MERGE(A, low, mid, high)
END IF

MERGE(A, low, mid, high)
    Create left = A[low..mid]
    Create right = A[mid+1..high]
    i = 0, j = 0, k = low
    WHILE i < len(left) AND j < len(right)
        IF left[i].marks >= right[j].marks
            A[k] = left[i]
            i = i + 1
        ELSE
            A[k] = right[j]
            j = j + 1
        k = k + 1
    END WHILE
    Copy remaining elements

Complexity Analysis

CaseTime Complexity
Best CaseO(n log n)

Auxiliary SpaceO(n)

There are O(log n) levels of recursion. Each level performs O(n) merge work. Therefore: O(n) × O(log n) = O(n log n).
